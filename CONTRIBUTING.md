# Contributing to Material Submittal Generator

Built from real MEP construction workflows. If you deal with material submittals, your real-world edge cases are gold.

## Ways to Contribute

- **Report bugs** — Open an [Issue](../../issues) with your template type + error output
- **Suggest features** — Start a [Discussion](../../discussions) to talk through ideas
- **Share templates** — Minimal de-identified `.xlsx` templates help us test against real patterns
- **Submit PRs** — See below

## Pull Request Process

1. Fork the repo and create a branch (`feat/description` or `fix/description`)
2. Keep changes focused — one feature or fix per PR
3. Test with a real `.xlsx` template
4. Open a PR against `main`

## Code Style

- Python 3.8+
- Type hints where practical
- Comments in English
- Docstrings for public methods

## Questions?

Start a [Discussion](../../discussions). This tool was born on real construction sites — your questions help make it better for everyone.
